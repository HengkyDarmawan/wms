When to use which

Gridstack.js
Column-based dashboards where widgets must not overlap and the layout needs to be saved and restored per user.
Interact.js
Free positioning: diagram editors, seat maps, floor plans, anything that is not a grid.
SortableJS
Reordering lists and moving cards between columns. Simpler than both when order is all you need.
