How nesting works

A submenu item can itself be a .nx-menu-item.has-submenu, holding another .nx-submenu. The deeper list gets .nx-submenu-deep, which only shifts the indentation — all the open/close behaviour is Bootstrap's collapse, so no extra JavaScript is involved.
