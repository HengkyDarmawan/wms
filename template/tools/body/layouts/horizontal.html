About this layout

The sidebar is hidden and the same menu data is rendered as a horizontal bar under the header. Nothing else changes: the header, footer, theme handling and command palette are identical.

How it is switched on

<body data-nx-layout="app"
      class="nx-layout-horizontal">

The class hides .nx-sidebar and drops the left margin on .nx-main. Below 992px the bar scrolls horizontally rather than wrapping, so it stays one line tall.
